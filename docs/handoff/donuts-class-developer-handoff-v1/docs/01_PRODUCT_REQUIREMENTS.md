# 01. Product Requirements — DO:NUTS CLASS

## 1. Product scope
DO:NUTS CLASS는 대학 포커 동아리연합 DO:NUTS의 회원·클래스·학교동아리·모임·파트너·학습을 관리하는 모바일 우선 웹앱이다.

### 핵심 사용자
- 전체 관리자: DO:NUTS 전체 회장 및 개발진 전용. 실서비스에서는 별도 관리자 페이지/주소 권장.
- 클래스장: 자신이 맡은 클래스 운영.
- 동아리장: 자신이 맡은 학교 동아리 운영.
- 일반회원: 클래스/동아리 활동 참여.
- 한 회원이 클래스장과 동아리장 권한을 동시에 가질 수 있다.

## 2. 데모 계정
| 유형 | 이름 | 데모 아이디 | 비밀번호 | 회원 DB 포함 |
|---|---|---|---|---|
| 관리자 | 한승목 | admin | 1234 | 아니오 |
| 동아리장 | 이민찬 | minchan | 1234 | 예 |
| 클래스장 | 조용훈 | yonghun | 1234 | 예 |
| 일반회원 | 이종한 | jonghan | 1234 | 예 |

**TO BUILD:** 실서비스에서는 로그인 유형을 사용자가 임의 선택하는 방식이 아니라 계정 권한을 서버에서 조회한다. 클래스장/동아리장 권한이 있으면 로그인 직후 `관리뷰 / 회원뷰` 선택 화면을 보여준다.

## 3. 가입 플로우
운영 플로우:
1. 구글 신청폼 작성
2. 현장 방문
3. 현장에서 DO:NUTS CLASS 웹 가입신청
4. 승인권한 보유자가 승인
5. 승인 후 로그인 가능

### 가입신청 필수 입력
- 이름
- 전화번호
- 아이디
  - 중복 불가
- 비밀번호
- 비밀번호 확인
- 학교
  - 관리자가 관리하는 학교 선택지
  - `기타` 선택 시 직접 입력
- 동아리
  - 현재 기본값: `없음`, `서울대학교 ATC`
  - 관리자가 CLUB을 추가하면 자동 선택지에 반영
- 클래스
  - 현재 기본값: 월요일 A / 수요일 A / 수요일 B / 금요일 A
  - 관리자가 CLASS를 추가하면 자동 선택지에 반영
- 개인정보/활동정보 수집 동의 체크박스
  - 동의하지 않으면 제출 불가

### 가입 상태
- `PENDING`: 승인 대기
- `ACTIVE`: 승인 완료
- **RECOMMENDED:** `SUSPENDED`, `WITHDRAWN` 추가

### 가입 승인 권한
- 관리자: 모든 가입신청
- 클래스장: 자신이 맡은 클래스로 신청한 회원
- 동아리장: 자신이 맡은 동아리로 신청한 회원

## 4. 관리자 메뉴
관리자 메뉴는 아래 5개만 유지한다.

| 탭 | 목적 | 생성 | 수정 | 삭제 |
|---|---|---:|---:|---:|
| MEMBERS | 회원 승인·소속 관리 | 가입신청으로 생성 | O | O |
| CLASS | 클래스 관리 | O | O | O |
| CLUB | 학교 동아리 관리 | O | O | O |
| MEETINGS | 실제 모임 일정 관리 | O | O | O |
| PARTNERS | 제휴 파트너 관리 | O | O | O |

리그 전용 탭은 없다. 학교 대표전 등도 MEETINGS에서 관리한다.

## 5. MEMBERS
### 기본 화면
- 목록 뷰
- 검색: 이름 / 아이디 / 전화번호
- 필터: 승인상태 / 클래스 / 동아리 / 학교
- 기본은 조회 전용

### 수정 모드
관리자가 `수정 모드`를 활성화하면 회원 카드를 눌러 아래 항목 수정:
- 이름
- 전화번호
- 아이디
- 비밀번호 재설정
- 학교
- 동아리
- 클래스
- 승인상태
- 회원 삭제

클래스장/동아리장 권한은 MEMBERS에서 직접 부여하지 않고 CLASS/CLUB 편집 화면에서 해당 회원을 리더로 선택한다.

## 6. CLASS
### 클래스 기본정보
- 장소
- 요일
- 시간
- 클래스명
  - 기본명 자동 생성: `DO:NUTS CLASS·월요일 A`
  - 같은 요일 클래스가 이미 있으면 다음 알파벳 자동 배정
  - 관리자가 임의 수정 가능
- 클래스장
  - 회원 이름 또는 아이디 검색
  - 최소 1명 필수
  - 여러 명 추가 가능

클래스 설명/운영상태 필드는 별도로 두지 않는다.

### 클래스 회차
- 최소 1개 ~ 최대 12개
- 각 회차 필드:
  - 회차 이름
  - 회차 설명
- 회차 추가/삭제 가능
- 일반회원 화면에서는 세로 진행도 UI로 표시

### 회차 상태
- 예정
- 진행
- 완료
- 모임 취소는 별도 플래그

### 클래스장 관리
- 담당 클래스 목록
- 회차 클릭 → 회차 관리
- `클래스 시작`: 예정 → 진행
- `시작 취소`: 진행 → 예정
- `모임 취소` / `취소 해제`
- 출석 명단 체크
- `출석 체크 완료` 시 체크박스 잠금
- 잠금 후 버튼은 `출석 수정`
- 수정 후 다시 `완료`하면 재잠금
- `클래스 완료`: 진행 → 완료

## 7. CLUB
### 동아리 정보
- 동아리명
- 학교
- 설명
- 로고 이미지
- 동아리장
  - 회원 이름/아이디 검색
  - 최소 1명 필수
  - 여러 명 가능

현재 기본 동아리: 서울대학교 ATC.

## 8. MEETINGS
### 공통 필드
- 주최
- 모임명
- 날짜
- 시간
- 장소
- 설명
- 정원
  - 0 또는 null = 미설정
- 게스트 허용
- 참가신청 ON/OFF
- 신청 마감 여부
- 신청자 목록
- HOT 여부
- 완료 여부/완료시각
- 생성자

### 주최 규칙
- 관리자가 개설: 주최는 `DONUTS` 고정
- 동아리장이 개설: 자신이 맡은 동아리로 자동 지정
- 동아리장은 본인이 생성한 일정만 수정/삭제
- 관리자는 전체 일정 관리 가능

### 게스트
- 게스트 OFF: `동아리 모임`
- 게스트 ON: `오픈 모임`

### 참가신청
- 기본 ON
- ON일 때만 신규 신청 가능
- OFF로 바꿔도 기존 신청자 목록은 삭제하지 않음
- 다시 ON으로 바꾸면 기존 신청자 그대로 유지
- 회원 카드 상태:
  - 신청 가능 + 미신청: `ON`
  - 신청완료: `✓ 신청완료`
  - 참가신청 OFF: `OFF`
  - 정원도달/신청마감: `마감`
- 신청 시 확인 팝업
- 신청완료 버튼 재클릭 시 취소 확인 팝업
- 본인 신청 취소 가능

### 정원
- 정원이 설정된 모임은 `신청자수/정원`으로 표시
- 정원 도달 시 신규 신청 마감

### HOT
- 관리자가 각 모임을 HOT 체크 가능
- 일반회원 CLUB 목록에서 HOT 모임을 최상단 정렬
- HOT 카드 시각 강조

### 모임 완료
- 관리자/해당 동아리장이 `모임 완료` 가능
- 완료 확인 팝업에 `24시간 뒤 목록에서 삭제되며 DB 기록은 유지` 안내
- 완료 즉시 참가신청 OFF
- 완료 후 24시간까지 일반 목록에서 `OFF` 상태로 존재
- 24시간 후 활성 목록에서는 제거
- 실제 DB에서는 soft archive/history로 영구 보존

## 9. PARTNERS
- 목록 뷰
- 노출 순서 관리
- 카드 클릭 → 정보 수정
- `삭제 버튼 표시` 모드에서 각 카드 삭제 가능
- 필드:
  - 이름
  - 설명
  - 로고 이미지
  - URL
  - 순서
- 상태 필드 없음

## 10. MEMBER UI
하단바:
- CLASS: 무채색 심볼
- CLUB: 무채색 심볼
- HOME: 무채색 홈 심볼
- PARTNERS: 무채색 심볼
- MY: 무채색 심볼
- 활성 메뉴만 브랜드 옐로우 강조

### 일반회원 CLASS
- 본인 클래스의 1~12회차 진행도
- 각 회차: 제목 / 설명 / 상태
- 30분 참여형, 메인토너먼트, 사이드게임 별도 영역 없음
- 본인 출석 여부는 해당 클래스 회차 내에서 확인

### 일반회원 CLUB
- 내 동아리 모임 + 참가 가능한 오픈 모임 통합 목록
- 학교모임/오픈모임 상태와 설명 표시
- HOT 상단
- 날짜 아래 시간 상하 배치
- 상세 → 참가신청/취소

### MY
- 회원 기본 정보
- 소속 학교/동아리/클래스
- 관련 화면 바로가기
- 별도 출석기록 메뉴 없음

## 11. Demo seed requirements
- 전체 회원: 50명, 한국 이름
- ATC 회원: 15명
- 이민찬: ATC 동아리장
- 조용훈: 월요일 A 클래스장
- 나머지 클래스장: 회원 중 임의 지정
- 이종한: 일반회원 기본 데모 사용자
- 한승목: 관리자, 회원 50명에 포함하지 않음
