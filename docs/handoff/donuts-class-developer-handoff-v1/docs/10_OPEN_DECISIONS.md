# 10. Open Decisions for Product Owner

아래는 개발 전 또는 MVP 중 확정하면 좋은 항목.

## XP
- [ ] 클래스 출석 XP 정확한 값
- [ ] 일일학습 완료 XP 정확한 값
- [ ] 100% 정답 보너스 여부
- [ ] XP 레벨 시스템을 MVP에 넣을지
- [ ] 출석 완료 후 정정 시 XP 회수 정책

## Daily learning
- [ ] 하루 문항 수: 권장 5
- [ ] 문제 출처: 자체제작 / GTO Wizard 참고 / solver export 등
- [ ] 저작권/라이선스 확인 방식
- [ ] 난이도 분리 여부
- [ ] 모든 회원 동일 세트 vs 개인화
- [ ] streak freeze 여부
- [ ] 정답률/취약포지션 분석을 V1에 넣을지

## Class
- [ ] 관리자도 회차 시작/출석/완료를 직접 수정할 수 있게 할지
- [ ] 실제 회차별 날짜를 DB에 둘지, 매주 규칙에서 계산할지
- [ ] 휴강/시험기간으로 날짜 skip 기능

## Meetings
- [ ] 완료 후 24시간을 정확한 timestamp로 할지 다음날 자정으로 할지 — 현재 요구는 24시간
- [ ] 삭제된 활성목록의 과거 모임을 회원이 MY에서 볼지
- [ ] 관리자가 신청자를 강제 추가/취소할 수 있는지
- [ ] 신청 대기/승인제는 필요 없는지 — 현재는 신청 즉시 완료

## Membership
- [ ] 전화번호 인증 필요 여부
- [ ] 비밀번호 찾기 방식
- [ ] 학교 이메일 인증 필요 여부
- [ ] 탈퇴/정지 정책
